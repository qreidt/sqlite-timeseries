# 0012. License

- Status: Proposed
- Date: 2026-11-13
- Settled by: [CQR-136](https://linear.app/cqr/issue/CQR-136)

## Context

The license must suit both Rust ecosystem norms and embedding in commercial apps.

## Options

- MIT.
- Apache-2.0.
- MIT / Apache-2.0 dual.

## Decision

MIT / Apache-2.0 dual, the Rust ecosystem default.

## Consequences

Both license files ship in the repository and in every package.
